Learning objectives & laboratory method — Signal synthesis and receiver processing

Learning objectives. Relate RINEX observation codes to carrier frequency, ranging codes and receiver observables. Compare code chips, navigation bits and data/pilot components.

Suggested method. Select an epoch, constellation, satellite and signal; inspect the data evidence; then follow carrier, PRN, modulation and receiver stages. Record units, sequence identity and the assumptions used.

Interpretation limits. RINEX contains observables and decoded navigation parameters, not raw RF samples. Acquisition and tracking visualizations are teaching models; successful PRN checks do not establish end-to-end receiver or full ICD conformance.

Academic definitions & PRN terminology
PRNA deterministic pseudo-random ranging sequence assigned to a satellite or signal component.
ChipOne binary element of a spreading/ranging sequence; it is distinct from a navigation data bit.
Chipping rateNumber of code chips transmitted per second.
Code phaseReceiver estimate of where the locally generated code aligns with the received code.
Gold codeSequence family formed from preferred maximal sequences with controlled correlation properties.
Memory codeA published sequence stored explicitly rather than generated solely from a short recurrence.

STAGE 6 / MATCHED REPLICA

Correlation Laboratory

The receiver slides a locally generated ICD replica across code phase. A strong peak identifies alignment; low sidelobes and low cross-correlation help separate channels.

R(τ) = Σ r[k] · c[k − τ]
AUTO-CORRELATION

Selected PRN correlation peak

INTERPRETATION

Why the peak matters

Code delay: the peak location estimates the signal propagation delay modulo the code period.

Pseudorange: receiver timing and decoded transmit-time information resolve the measurement into a range-like observable.

Satellite discrimination: CDMA systems exploit different PRN codes; legacy GLONASS additionally separates satellites by FDMA carrier channel.
